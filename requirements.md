# Project Requirements

## 1. Language
- Java 21

## 2. Libraries and Frameworks
- JUnit 5 for unit testing
- Maven for project management

## 3. Features
- Calculator class with methods for addition, subtraction, multiplication, and division

- JUnit 5 tests for all methods in StringUtils
